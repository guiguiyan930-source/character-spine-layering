# character-spine-layering
按 Spine 骨骼动画需求拆解角色/游戏人物立绘。先由动作清单确定骨骼树，再由骨骼推导插槽、附件和切图，最终输出可直接导入 Spine 4.2 的骨骼 JSON、切图和带 Spine 标签的分层 PSD。部件与原图同坐标、同比例；眼睛、眉毛、鼻子、嘴巴、手、武器、衣服都是语义完整的单个物体，不是抠图或裁切碎片；遮挡、出画、误删处自动补全；关节重叠量按动作旋转角计算，衣服先与身体分离补全再按骨骼合并，动作中不露底。适用场景：Spine 动画拆图、角色骨骼绑定素材、需要拆到哪一层、眨眼/口型/手型附件、按动作清单拆分、遮挡补全、衣服与身体分层或合并。
